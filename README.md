## Cómo ejecutar localmente

No se requieren dependencias externas. El proyecto puede abrirse directamente en el navegador:

1. Clonar o descargar el repositorio.
2. Abrir `index.html` en el navegador.
3. También puede usarse la extensión Live Server de Visual Studio Code si se desea recarga automática.

## Cómo publicar en GitHub Pages

1. Subir el proyecto a un repositorio de GitHub.
2. Entrar a `Settings` del repositorio.
3. Abrir la sección `Pages`.
4. En `Build and deployment`, seleccionar la rama principal, normalmente `main`.
5. Seleccionar la carpeta raíz `/root`.
6. Guardar los cambios y esperar a que GitHub genere la URL pública.

## Cómo personalizar el portafolio

- Textos principales: editar las secciones dentro de `index.html`.
- Proyectos: modificar las tarjetas dentro de la sección `#proyectos` y sus textos bilingües en `js/script.js`.
- Imágenes: reemplazar los archivos en `assets/img/` y mantener rutas equivalentes.
- Enlaces: actualizar los atributos `href` de GitHub, LinkedIn, demos y repositorios.
- Correo: cambiar el texto del correo en la sección de contacto.
- CV: reemplazar los archivos `assets/EN-Luis-Diego-Montero-CV.pdf` y `assets/SP-Luis-Diego-Montero-CV.pdf`, o actualizar las rutas de los botones.
- Idiomas: editar el objeto `translations` dentro de `js/script.js` para ajustar textos en español o inglés.
